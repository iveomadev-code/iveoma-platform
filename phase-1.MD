# 1. DESIGN SYSTEM DIRECTION

### Explanation (Brief)

We are defining a **visual language that signals trust, global credibility, and human impact**—not a generic NGO aesthetic. It should feel like a **hybrid of editorial storytelling + modern SaaS clarity**.

---

## 🔷 Antigravity Prompt — Color System Exploration

**Prompt:**

> Create a premium, globally credible color system for a philanthropy and development NGO.
>
> Base the palette on:
>
> * Primary: Deep navy (#174A76) for authority and structure
> * Secondary: Soft sky blue (#6CA4D5) for openness and humanity
> * Accent: Controlled red (#E0292B) for calls-to-action and urgency
> * Neutrals: White, soft grey (#F5F7FA), charcoal (#1F2A33)
>
> Add 2–3 complementary tones that elevate the system (muted gold, desaturated teal, cool grey variants).
>
> Define:
>
> * Background hierarchy (primary, secondary, inverse)
> * Text hierarchy (heading, body, subtle)
> * UI usage (buttons, links, highlights, dividers)
>
> Avoid overly vibrant or playful palettes.
> Output should feel institutional, refined, and globally credible (not startup-like).

---

## 🔷 Antigravity Prompt — UI Principles & Design Language

**Prompt:**

> Define a UI design language for a high-end NGO digital platform.
>
> Principles:
>
> * Minimal but not cold
> * Human-centered, with emotional depth
> * Editorial storytelling meets SaaS clarity
>
> Define:
>
> * Visual hierarchy rules (how attention flows)
> * Use of whitespace (generous, intentional spacing)
> * Image treatment (documentary-style, high authenticity)
> * Icon style (simple, geometric, non-illustrative)
> * Card system (subtle elevation, no heavy shadows)
>
> Avoid:
>
> * Overdesigned NGO clichés
> * Loud gradients or trendy effects
>
> Output should feel like a blend of:
>
> * Global NGO credibility
> * Premium product design system

---

>

Typography should feel:

* Global
* Editorial
* Calm authority

---

## 🔷 Recommended Pairing (Primary)

* **Sora (Headings)**
* **Inter (Body)**

Optional accent:

* **Caveat** (very sparing, human touch)

---

## 🔷 Antigravity Prompt — Typography System

**Prompt:**

> Create a premium sans-serif typography system for a global NGO platform.
>
> Use:
>
> * Headings: Sora (modern, geometric, confident)
> * Body: Inter (high readability, neutral, professional)
>
> Define:
>
> * Type scale (H1–H6, body, small text)
> * Font weights and usage rules
> * Line heights for readability
> * Letter spacing for headings
>
> Include:
>
> * Editorial-style large headings (impactful but calm)
> * Clean body text for long-form storytelling
>
> Optional:
>
> * Introduce a subtle handwritten accent (e.g., Caveat) used only for highlights or quotes
>
> Avoid:
>
> * Overly stylized typography
> * Tight, dense layouts
>
> Output should feel premium, readable, and globally credible.

# 5. MOTION & INTERACTION SYSTEM

### Explanation (Brief)

Motion should:

* Guide attention
* Reinforce hierarchy
* Feel natural (physics-based)

---

## 🔷 Antigravity Prompt — Motion Philosophy

**Prompt:**

> Define a motion design system for a premium NGO website built in Framer.
>
> Principles:
>
> * Subtle, purposeful motion
> * Physics-based easing (natural acceleration/deceleration)
> * Motion used to guide attention, not decorate
>
> Define:
>
> * Entrance animations (fade + slight translate)
> * Hover interactions (micro-feedback)
> * Scroll-based storytelling transitions
>
> Timing:
>
> * Fast interactions (150–250ms)
> * Section transitions (300–600ms)
>
> Avoid:
>
> * Bouncy, playful animations
> * Overuse of motion
>
> Output should feel calm, refined, and intentional.

---

## 🔷 Antigravity Prompt — Interaction Patterns

**Prompt:**

> Design interaction patterns for a modern NGO platform with a premium feel.
>
> Include:
>
> * Button interactions (hover, press states)
> * Card hover effects (subtle elevation or scale)
> * Link transitions (smooth, understated)
> * Scroll-triggered reveals
>
> Define:
>
> * Consistent interaction rules across the system
> * Feedback loops (user always understands what's happening)
>
> Ensure:
>
> * Accessibility is maintained
> * Interactions never distract from content
>
> Output should feel polished, modern, and intuitive.
